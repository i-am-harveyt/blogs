# What Is Git?

Git is:

- Version Control System VCS
- Created by Linus Torvalds, the creator of Linux
- Distributed in architecture, hence the abbreviation DVCS

## What Is a VCS, and Why Make It Distributed?

A VCS is a version control system. But why do we need to control versions?

Imagine happily finishing some code changes and releasing a new version of your software.
Then you go out for a delicious dinner with friends.
After dinner, you discover that your Gmail inbox is overflowing: customers have hit a serious bug in the new version, badly affecting their experience.

What is your instinct? Probably the same as mine: roll back to the previous version so they can at least keep using it.

But here are the problems:

- You have changed the code extensively. How do you return to the previous version?
- Suppose you diligently archive your code after every session. Which archive is the one you need?

Careful file organization might help you find it efficiently, but in my experience that is a lot of work.

I think engineers are lazy creatures, always looking for ways to make their jobs easier.
~~Sometimes putting their own jobs at risk, such as by trying to build AI coders.~~
Back to the point: version control systems were created to let you:

- Manage versions easily
- Use a consistent version history and rollback mechanism

This lets you quickly find an earlier version and restore the code to its state at that point.

The distributed part is easier to picture: we are not all sharing one computer, one directory, and one code file.

Coordinating work from people in different places is what the distributed system enables.

We will not cover the architecture, design philosophy, or underlying mechanisms here. Feel free to look them up.

## What Is GitHub?

GitHub is:

- A code collaboration platform; think of something like Google Docs for code
- Closely integrated with Git, as its name suggests
- A place where you can perform some Git operations

In collaborative development, we generally use Git to manage versions and GitHub to work together.
