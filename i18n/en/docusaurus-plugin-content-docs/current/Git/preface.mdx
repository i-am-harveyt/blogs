# Getting Started Without Giving Up

I once saw a chapter title like this in a book, and it stayed with me. Now I am borrowing it.

And yes, Git is only part of the story. I have picked up and put down plenty of things along the way.

I want to share a few thoughts. Feel free to skip them or treat them as a bit of rambling.
But if you are thinking of giving up, I hope you will read on and find some encouragement or inspiration.

## Git Is Everywhere: Learning It Early Pays Off

To me, _**Git is a pillar of collaborative software development around the world**_.

At the broader level,
Git is usually the default choice when people talk about version control.
GitHub is also one of the most prominent hosting platforms.

On a personal level,
I have used Git for my own projects, school projects, freelance work, and internships.
It is no exaggeration to say that Git is everywhere in my life now.

## Start Now Instead of Waiting Until the End of the Semester

As a version control tool, Git has many uses.

You can use it to manage your notes. Believe me, I really did manage my Obsidian notes that way.
I only stopped because I fell out of the habit of taking notes.

Even better, start using it for a side project right after today's session.

It is the first week of the semester. Ideally, you will be comfortable with Git before work on the final project begins.

Imagine having capable teammates who can all write code but do not know version control.
Several people will be working together and running into collaboration problems everywhere.
That affects the entire project development experience.

Here is a painful experience of mine. If you have worked on projects, you may relate.
If not, you may be able to imagine it by the end of this semester:
A teammate once pushed directly to `main`, overwriting `package_lock.json` while we were dealing with a conflict in that file.
It was frustrating.

## You Are Not Alone

I believe you can soon learn the things I have learned.
Our starting points are probably similar:

- My first language was Java too, although I do not enjoy writing it.
- I encountered Git after one semester. I understood almost nothing and just repeated `add`, `commit -m "update"`, and `push`.
- I once thought, "What is this strange thing? I never want to use it again."

Step by step, I came to appreciate Git's importance. Now, as I said, it is everywhere in my life.

If you get stuck while learning, search for help, whether through Google or GPT.
With so many people using Git, your problem is probably not new. Someone else has likely encountered it.
If you do not know how to ask, you are welcome to talk to me.
If I have hit the same problem, I can help.
If I have not, we can work it out together.

## Closing Thoughts

Finally, I want to leave you with this:
_**Faced with the vastness of knowledge, we are all learners.**_
Let's encourage one another.
