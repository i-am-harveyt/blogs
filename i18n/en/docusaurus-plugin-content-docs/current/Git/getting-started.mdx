# Getting Started

Run `git --version` to check whether Git is already installed.

## Windows

I recommend installing [Git Bash](https://git-scm.com/downloads).

You may want to look up recommended settings. I personally tend to click "Next" through the installer.

Suggested search terms: "Git Bash" "Windows" "install" "config"

## MacOS

Install the Xcode command line tools.

```bash
$ xcode-select --install
```

This installs more than Git, including tools such as `gcc`, so it may take a while.

## Essential Setup

Use these two commands to set the name and email recorded in your commits:

```shell
$ git config --global user.name "Your name"
$ git config --global user.email your.email@example.com
```
