# Create a New Repo

Find the green "New" button on your homepage, or click [here](https://github.com/new).

Use the settings shown in the image. I see an error because I already created a repository with this name; you should not have that problem. It also shows what happens when a name is taken.

![image](https://hackmd.io/_uploads/HJOAX3jwJx.png)

Click "Create repository" to finish. The result should look like this:

![image](https://hackmd.io/_uploads/SJuL42oDJl.png)
