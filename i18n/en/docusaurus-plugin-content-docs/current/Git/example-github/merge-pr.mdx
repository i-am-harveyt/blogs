# Merge Pull Request

![image](https://hackmd.io/_uploads/BJHXbyhwkx.png)

GitHub checks for conflicts. If there are no conflicts and the required reviews are approved, you can merge.

:::note[What happens if there is a conflict?]
You need to resolve it.
Try deliberately creating a conflict as an exercise.
If you can create and resolve one, you have understood the process.
Conflicts are common in collaboration, so you will probably encounter one sooner or later.
:::

Click `Merge pull request` to finish.
Afterward, a `Delete branch` button lets you delete `misc/gitignore`.
I usually do this to keep things tidy.
