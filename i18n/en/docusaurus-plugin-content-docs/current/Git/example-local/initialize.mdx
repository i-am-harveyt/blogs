# Initialize a Local Git Repo

Initialize a Git repository from the terminal:

```bash
$ git init
```

Git traditionally used `master` as the default branch name. Today, `main` is commonly used.
The examples below assume `main`. If yours is named `master`, rename it with `git branch -M main`.

Your Git graph now looks like this:

```mermaid
gitGraph
```
