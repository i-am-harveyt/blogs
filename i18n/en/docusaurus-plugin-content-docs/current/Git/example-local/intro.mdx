# Introduction

Let's start with something simple: using Git locally.

The examples use commands for a Unix-style shell.
You do not need to know what Unix means yet. Git Bash, bash, or zsh will work.

We will do everything in `~/Desktop/example/`, an example folder on your desktop. If you are unfamiliar with the terminal, you can create it by right-clicking on the desktop.

Here is a command to use:

```bash
$ mkdir ~/Desktop/example && cd ~/Desktop/example
```

If you are unsure whether it worked, run `pwd` to check your current directory.

At various points, I will include diagrams created with [Mermaid JS](https://mermaid.js.org/).
