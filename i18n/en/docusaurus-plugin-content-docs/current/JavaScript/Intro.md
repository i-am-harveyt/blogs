# Introduction

JavaScript (JS) is one of the world's [most widely used languages](https://www.statista.com/statistics/793628/worldwide-developer-survey-most-used-languages/).
It is almost impossible to avoid in web development, and many desktop applications use it too, including [Visual Studio Code](https://github.com/microsoft/vscode), which you may already be using.
TypeScript (TS) extends JS, but we will leave that for another time.

Let's start with a few characteristics of JS. Do not worry if they do not all make sense yet; later explanations and examples may help:

- Despite having "Java" in its name, it is *not an extension of Java*.
- It uses an *interpreter or a just-in-time (JIT) compiler*, rather than requiring all code to be compiled before execution:
  - For now, you can picture your code running one line at a time.
  - Compilation is still possible, but we will not discuss it here.
- It is a *dynamic language*: variable types are determined by the execution environment at runtime, rather than fixed at compile time.
- Functions are *first-class values*, meaning you can work with them as you would other values.

:::info
These materials are intended for people taking their first steps with JavaScript.

The main goal is to enjoy writing code, so the first half avoids difficult concepts.

If you already have a strong foundation in programming languages, I suggest looking at the [MDN docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript).
:::

Happy learning!
